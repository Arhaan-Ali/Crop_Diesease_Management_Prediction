

# 🌿 PlantGuard — AI Plant Health Detector (Frontend)

A modern, green eco-tech website with lively animations and a mock AI classification flow. No backend — results will be simulated with realistic mock data for now.

---

## Design System & Theme
- **Colors**: Emerald/mint/forest green gradients, white backgrounds, soft yellow accents
- **Style**: Glassmorphism cards, rounded corners, soft shadows, green glow effects
- **Animations**: Floating background shapes, animated gradient hero, fade-in sections, parallax, button hover glow/scale effects, smooth page transitions
- **Typography**: Clean sans-serif (Inter)

---

## Page 1: Home Page (`/`)
- Animated gradient background with floating leaf/plant shapes
- Hero section: bold headline ("Detect Plant Diseases Instantly with AI"), subtitle, glowing "Get Started" CTA linking to Detect page
- "How It Works" section: 3 step cards (Upload → Analyze → Results) with staggered fade-in animations
- Features section highlighting speed, accuracy, crop support
- Footer with nav links and social icons
- Smooth scroll entrance animations throughout

## Page 2: Detect Page (`/detect`)
- Centered glassmorphism card with drag-and-drop upload zone + "Upload Image" button
- On image upload:
  - Shows image preview
  - Animated loading spinner (2-3 second simulated delay)
  - Mock result appears with fade-in + slide-up animation
- Results card: green glowing border, disease name or "Healthy" status, confidence percentage, care tips, health icon
- Mock results rotate between a few realistic plant disease scenarios

## Page 3: Contact Page (`/contact`)
- Clean form: Name, Email, Message inputs with green focus glow
- Submit button with hover glow/scale animation
- On submit: animated success toast/message
- Social media icons with hover effects
- No actual email sending — just frontend validation and success feedback

---

## Shared Components
- Responsive navbar with green theme, mobile hamburger menu
- Animated page transitions between routes
- Consistent green glow hover effects on all interactive elements
- Fully responsive layout (mobile, tablet, desktop)
